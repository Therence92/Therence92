## Projet phare

### [Détection de fraude bancaire : du score de risque au gain en euros](https://github.com/Therence92/fraud-detection-cost-optimization)

- 283 726 transactions analysées en **SQL** (CTE, NTILE, fenêtres glissantes) : 10 % des transactions concentrent 78 % des pertes
- Modèle de détection évalué **en euros** : 58 % des pertes évitées sur une période jamais vue, contre 2 % pour une règle simple
- Seuil d'alerte optimisé selon le coût de revue, incertitude mesurée par bootstrap
- Dashboard **Power BI** de pilotage (11 mesures DAX)
